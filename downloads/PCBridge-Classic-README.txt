PCBridge Classic — старое управление мышью и клавиатурой

В этой версии оставлено: ПК → TCP → Android → Bluetooth HID → iPhone.
AirPlay-приём, зеркалирование, управление кликами по изображению, калибровка и Android-панель касаний удалены.

БЫСТРЫЙ ЗАПУСК
1. Распакуйте ZIP целиком. В Windows/ запустите PCBridge.exe и нажмите «Запустить сервер».
2. Установите Android/PCBridge-Classic.apk на Android (Android 9+). Разрешите устройства поблизости.
3. Включите AssistiveTouch на iPhone: Настройки → Универсальный доступ → Касание → AssistiveTouch.
4. На Android нажмите «Подключить HID», выполните Bluetooth-сопряжение с iPhone.
5. ПК и Android подключите к одной локальной сети. В Android введите IP ПК и нажмите «Подключить ПК».
6. В PCBridge включите Control mode. F12 выключает управление.
7. Если Windows спросит про брандмауэр, разрешите PCBridge для используемой домашней/частной сети.

На ПК не нужны AirPlay-приёмник, Bonjour или отдельно установленный .NET Runtime: Windows-сборка включает runtime.
Если Android не позволяет обновление из-за другой подписи/версии, сохраните необходимые локальные настройки, затем удалите старое приложение и установите APK из архива. Удаление приложения сбрасывает его настройки.

ЗАДЕРЖКА МЫШИ
- Удалён фиксированный таймер отправки мыши раз в 8 мс. Первая команда отправляется сразу по событию Raw Input.
- TCP_NODELAY включён; один упорядоченный отправитель не блокирует оконный поток сетевой записью.
- Когда сеть не успевает, соседние движения с одинаковым состоянием кнопок суммируются. Дельты больше диапазона HID разбиваются без потери остатка. Нажатия/отпускания и команды клавиатуры сохраняют порядок.
- На Android команды идут в HID напрямую, без таймеров движения, калибровки, циклов «сброса в угол» и задержек на касания.
- Разбор пакетов уменьшает число временных объектов; поток доставки ввода использует повышенный приоритет, если это разрешено Android.
- При разрыве связи отпускаются клавиши и кнопки; команды предыдущего соединения после переподключения не выполняются.

Полную задержку Bluetooth/iOS нельзя определить или обнулить программно в этой сборке. Она не измерялась на физических телефонах.
Для минимальной сетевой задержки подключите ПК по Ethernet, Android — к близкой точке Wi-Fi. Если мышь с опросом 8000 Гц вызывает отставание, используйте 125–1000 Гц: перегрузка Bluetooth может быть медленнее умеренной частоты. Настройку скорости указателя iPhone выберите под себя.

ИСХОДНИКИ
В Sources/AndroidBridge находится полный Android-проект. Sources/PCBridge — Windows WPF-проект, BUILD_WINDOWS.cmd создаёт win-x64-сборку.
Для Android нужны JDK 17, Gradle 9.8.0, Android SDK platform 35 и Build Tools 36.0.0:
    gradle --no-daemon assembleDebug testDebugUnitTest lintDebug
Готовый APK: app/build/outputs/apk/debug/app-debug.apk.
